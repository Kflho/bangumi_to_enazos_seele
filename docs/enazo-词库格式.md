# enazo 词库批量录入格式

来源：绘谜（enazo）词库批量录入页的格式说明，口述转写后按格式整理，字句未改。

## 原文

> 批量录入格式说明
>
> 通过换行进行分割多个词条
>
> 每行文字可以是如下格式：
>
> - 词条名
> - 词条名,别名一
> - 词条名，别名一
> - 词条名，别名一，别名二
> - 千反田爱瑠，千反田惠瑠,千反田 える；ちたんだ える、Chitanda Eru/吃蛋挞
> - 词条名，别名一，别名二、罗马文 发音;romaji hacuon/声优名
>
> 批量新建的词条默认属性会根据下面的模板进行批量创建，建议在备注中标明例如
> 角色所在动画之类信息。
>
> 小狐狸提示格式：通过 `$` 符号分割，后半到截止都是小狐狸提示文案。
>
> 示例：`测试词条$小狐狸文案，小狐狸2，小狐狸提示`

## 逐条拆解

**词条之间用换行分割。** 一行一个词条，解析器不跨行合并。单元格里的换行必须先压掉，
否则一条会被切成两条，后一段没有词条名，就是废行。

**一行的结构是「词条名 + 若干别名」，`$` 之后是可选的提示。**

```text
词条名,别名一,别名二$小狐狸提示
```

**别名分隔符不止一种逗号。** 示例里出现了这六种，都会被当成别名之间的切口：

| 字符 | 出现位置 |
|---|---|
| `,` 半角逗号 | `千反田爱瑠，千反田惠瑠,千反田 える` |
| `，` 全角逗号 | `千反田爱瑠，千反田惠瑠` |
| `、` 顿号 | `ちたんだ える、Chitanda Eru` |
| `；` 全角分号 | `千反田 える；ちたんだ える` |
| `;` 半角分号 | `罗马文发音;romaji` |
| `/` 斜杠 | `Chitanda Eru/吃蛋挞` |

**别名可以是任意一种叫法。** 官方示例里混着汉字写法、平假名、罗马字、声优名、作品梗
（吃蛋挞），凡是玩家可能敲进聊天框的说法都能放。

**`$` 之后全部是小狐狸提示。** 这里不再切分别名，整段都是提示文案。示例
`测试词条$小狐狸文案，小狐狸2，小狐狸提示` 说明多条提示用逗号并列写在 `$` 后面——
对动画题库来说，这就是同一部片的多条评论。

## 对生成脚本的约束

- 输出必须单行一条，源表格里的 Alt+Enter 换行不能原样留着：脚本把多段评论按行拆开、
  用逗号并列成多条提示（对应官方示例 `$小狐狸文案，小狐狸2，小狐狸提示`），不粘连；
- 六个分隔符出现在名字内部会被当成切口，词条名会被截断；
- 处理办法：默认把这些分隔符连同空白换成 `-`（`--dash all`），只换分隔符用
  `--dash seps`，全都不动用 `--dash none`；
- 不在格式里的字符（`☆ ♡ ！ ？ ： 「」` 这类）原样保留；
- 多个别名之间用半角逗号连接，不用 `、` `;` 充当连接符。
